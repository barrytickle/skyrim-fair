# Project interaction rule

Do not take control of Barry's computer or use UI/computer-control automation for this project.

- Do not click, type into, navigate, or otherwise interact with desktop applications, browser windows, game tools, or other graphical interfaces on Barry's behalf.
- If a task requires interaction with a GUI or another application, explain the required steps and leave the interaction to Barry.
- Wait for Barry to confirm the result before continuing with work that depends on that interaction.
- Non-interactive repository work and command-line build, inspection, and verification tasks remain allowed unless Barry says otherwise.
